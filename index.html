10,000 ft · What it stands on

One language under most of what you just verified.

The compiler. The MHD simulation that becomes the beacon. The server that publishes each pulse, and the signer on the witness. A TLS 1.3 stack. Each of those is Rail, and all of it compiles from a single ~0.9 MB seed binary you can read end to end. The rest, named plainly: the pulse signer is Python, this page is served by a Cloudflare Worker, and the button on the first screen checks signatures with your browser's own WebCrypto.

the compiler you run is the compiler you read

Being readable is the prerequisite, not the point. A compiler small enough to audit and reproducible enough to trust can act as a referee, which is what machine-written code has never had. A model's claim that its output is correct can't be checked by anyone. A compile can be re-run by everyone.

14,000 ft · The long bet

Every pulse now commits to the one before it.

The beacon ticks every 2 s. Kept up, that is roughly 220 million pulses by 2040. Since pulse format 2 (2026-10-19) each one hashes the one before it, and every deploy of this site is signed against the chain. Rewrite any old pulse and every later one changes, so every copy saved anywhere would disagree.
