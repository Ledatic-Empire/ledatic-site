How we keep this honest

Every file shown here is a byte-for-byte copy of what war.gov published. As bytes flow to disk we compute their SHA-256 in pure Rail and bind the digest to a live entropy beacon pulse, signed by an independent fleet0 Ed25519 witness. If the source ever quietly changes a file, we'll know. If we ever quietly change one, you can prove it.

It's a single Rail binary called pursue. Pure Rail TLS 1.3, streaming SHA-256, JSON. No curl, no SQLite, no libcrypto. Source is public. Run your own copy.
