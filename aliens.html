How we keep this honest

Every file shown here is a byte-for-byte copy of what war.gov published. As bytes flowed to disk we computed their SHA-256 in pure Rail and bound each digest to a live entropy beacon pulse, signed by an independent fleet0 Ed25519 witness. The prove button on every record replays that check here in your browser: it re-hashes our copy where the file fits the in-browser cap, and verifies the signature against the pinned public key either way.

The recurring comparison against the war.gov source is currently paused — the status chip above says so honestly. The signed digests don't pause: if the source ever quietly changes a file, re-checking against these attestations will show it, and if we ever quietly change one, you can prove it.

It's a single Rail binary called pursue. Pure Rail TLS 1.3, streaming SHA-256, JSON. No curl, no SQLite, no libcrypto. Source is public. Run your own copy.
