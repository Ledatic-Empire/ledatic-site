# honesty_allowlist.txt — prose allowlist for tools/honesty_gate.sh (spec §5.4).
#
# Format: one "glob|ERE" per line. A gate hit is exempt when the file path
# matches the glob AND the offending line matches the ERE. Keep every entry
# CONTENT-ANCHORED (a phrase from the real line), never blanket.
#
# Most entries below exist so the gate is green on day one of the 2040
# build-out, while the managed stats are still hand-typed. As Wave 2 page
# agents convert each literal to a <data class="fig"> Figure, delete the
# matching entry. Entries marked [keep] are permanently legitimate.

#    [keep] but page agents must update them when stats move. ─────────────

# ── Stat display blocks — Wave 2 converts each value to a Figure ─────────
