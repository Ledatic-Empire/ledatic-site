How to verify this verifier

This file is intentionally self-contained: no external scripts, no external CSS, no font CDN. The only thing it loads at runtime that is not in this file is the manifest you give it (either via the URL field above or pasted JSON).

To prove this file has not been tampered with, compute its SHA-256 and check it against the hash published at ledatic.org/provenance:

shasum -a 256 standalone.html
# or:  openssl dgst -sha256 standalone.html
# or:  sha256sum standalone.html  (Linux)

The expected hash is also published in this repo at tools/verify/README.md. If your local computation matches both publications, the file is what its author shipped.

The witness public keys baked in below are the same constants as the live verify.html on ledatic.org. They are also published on the provenance page footer; cross-check both.

Browser support: Chrome 137+, Safari 17+, Firefox 138+ for Ed25519 in WebCrypto. SHA-256 (used for the inner-digest check) works everywhere.
